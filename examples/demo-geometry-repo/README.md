# Demo Geometry Core

Demonstration repository for Multi-Agent Collaboration Hub.

## Structure
- `circle.js`: Circle calculations (area, circumference) - implemented by Developer Agent 1
- `rectangle.js`: Rectangle calculations (area, perimeter) - implemented by Developer Agent 2
- `test_circle.js`: Isolated test for circle functions
- `test_rect.js`: Isolated test for rectangle functions
- `test_geom.js`: Integrated test across both modules
