## 二、证明了什么

| 断言 | 结果 |
|---|---|
| 拒绝不会自动返工 | ✅ 拒绝后任务停在 `waiting_approval` |
| 返工必须显式发起 | ✅ `POST /subtasks/{FINAL-REVIEW}/rework` → 202，落到 IMPL、`retry_wait` |
| 旧审批失效 | ✅ approval#1 终态 `rejected`，不会被复用 |
| 新审批绑定新内容 | ✅ 新 `actionDigest` 不同，`artifactRefs` 从 6 变 5 |
| 第二次是真实重跑 | ✅ 4 个 run、4 个不同 session |
| 仓库隔离 | ✅ HEAD 未变、工作区干净 |

## 三、一个小观察

新旧审批的 `artifactRefs` 数量不同（6 → 5），差异来自 FINAL-REVIEW 那份**空 diff 产物**（`e3b0c442…`）。这说明"新审批只绑当前 attempt 的产物"是成立的，也再次印证空 diff 产物会污染计数（已在 DS-04/DS-02 报告里提过）。
