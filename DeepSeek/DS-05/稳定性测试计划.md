## 1. 目标与非目标

**目标**：给出这台 8 GB 机器上"能连续用多久、会涨多少内存/磁盘、出问题怎么发现"的可复现数据，并据此修 `LOCAL-START.md` 与使用说明。

**非目标**（不得顺带标为完成）：

- 并发 > 1；Windows；跨厂商；完整 Agent 读隔离；多日长稳（本轮最长 90 分钟）；崩溃无损续跑（那是 DS-03）。

## 2. 测试阶段（每阶段独立结论）

| 阶段 | 时长 | 内容 | 额度成本 |
|---|---|---|---|
| T1 空载 | 30 min | 只起服务 + 保持 1 条 SSE 连接，不建任务 | 0 |
| T2 顺序任务 | 45 min | 3 个真实小任务依次完成（含审批） | 约 3–6 次调用 |
| T3 SSE 压力 | 10 min | 在 T2 期间人为断线重连 10 次（关标签/断网模拟） | 0 |
| T4 重启 | 10 min | 在空闲与"有历史任务"两种状态下各重启一次 | 0 |
| T5 异常入口 | 10 min | 错误配置、端口占用、缺 codex、缺 git 各一次 | 0 |

合计约 90 分钟、3–6 次真实调用。T1/T3/T4/T5 完全无额度。

## 3. 观测指标与采样方法

| 指标 | 采样命令（在用户 Terminal 里跑，我的沙箱禁 `ps`） | 判据 |
|---|---|---|
| 控制器 RSS/CPU | `ps -o pid,rss,%cpu,etime,command -p <hub_pid>` 每 5 min 一次 | 30 min 空载 RSS 增长 < 20%；T2 结束回落不明显增长 |
| 系统内存压力 | `memory_pressure \| tail -3`、`vm_stat \| head -6` | 不出现 swap 持续增长 |
| SQLite 体积 | `du -h runtime/state/agetor.sqlite*` 每阶段末 | 增量为任务数的线性函数；WAL 不无限增长 |
| 日志体积 | `du -sh runtime/state`、最大单文件 | 单任务日志 < 5 MiB（当前上限 1 MiB/run 输出 + 500 行/页） |
| workspaces 回收 | `du -sh runtime/workspaces`、`ls runtime/workspaces \| wc -l` | 任务结束后数量稳定，不随任务数无限累积 |
| SSE 连续可用 | `curl -N -H "Authorization: Bearer …" http://127.0.0.1:4322/api/v1/events` + 前端状态 | T3 十次重连后仍能收到事件，无 `EVENT_CURSOR_EXPIRED` 未恢复 |
| 任务结果 | `GET /api/v1/tasks` 统计 succeeded/failed | T2 中 3/3 succeeded |
| 重启一致性 | 重启前后 `run/subtask/task` 计数与状态 | 无 `interrupted`/`blocked` 残留（除非 T4 特意在活动中重启） |
| 端口与残留 | `lsof -nP -iTCP:4322 -sTCP:LISTEN`、`pgrep -fl codex` | 停止后无监听、无孤儿 codex（**T2 结束尤其要查**） |

每 5 分钟一次采样的最小脚本（用户侧）：

```sh
HUB_PID=$(lsof -nP -iTCP:4322 -sTCP:LISTEN -t)
while sleep 300; do
  date -u +%FT%TZ
  ps -o pid,rss,%cpu,etime -p "$HUB_PID" | tail -1
  du -sh "$RUNTIME/state" "$RUNTIME/workspaces"
  lsof -nP -iTCP:4322 -sTCP:LISTEN | wc -l
done | tee stability-samples.log
```

## 4. 判定标准

- **通过**：T1 30 min 无泄漏趋势；T2 3/3 succeeded 且结束后无孤儿进程、workspaces 数量稳定；T3 十次重连全部恢复；T4 重启后状态一致；T5 五个异常入口都给出可读错误而不是栈崩溃。
- **降级通过**：出现可解释的线性增长（例如每次任务固定 +2 MiB），记录斜率并给出上限建议。
- **不通过**：内存单调增长不回落、孤儿 codex 进程残留、重启后出现 `interrupted` 残留且无解除入口（与 DS-03 的静态发现联动）。
