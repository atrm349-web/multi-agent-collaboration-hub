# Codex 后端任务统一入口 v0.2

本文件替代原文件中冲突的 C-01～C-06 编号。具体编号/状态见 task-board.md；HTTP/SSE以api-contract.md为准，不要求后端照搬旧Mock状态机。

顺序：D-01选型→B-01安全策略→B-02执行器→B-03持久化/恢复→B-04规划调度与B-05验收→B-06隔离集成→I-01。允许在B-01后提前做B-06边界验证，但并行代码写入在隔离验证前禁用。

验收重点：

- B-01：任何关联Worktree外部Git写入均不得自动提权；Agent不能默认整机无限访问；禁止未授权适配器自动启用。
- B-02：真实启动/终态、取消进程组、超时区分、明确session恢复。pause先停止派发，不要求所有CLI进程即时挂起；300ms仅作为待测性能目标，不是已承诺SLA。
- B-03：事务幂等claim、lease、outbox与启动对账；重启不丢日志，不对不确定副作用盲目重放。
- B-04：DAG无环/引用/数量/权限校验；未知CLI返回明确不可用，不静默Mock；规划预览不执行生成代码。
- B-05：独立测试+产物哈希+审批摘要+有限返工；模型自报不作为完成；不自动reset/删除冲突分支。
- B-06：独立目录与分支、共享Git元数据协调、失败保留证据、合并冲突返回WORKTREE_CONFLICT。
- R-01：后续独立可行性预研，不默认订阅转API额度。

提供真实后端联调命令时必须说明端口、临时令牌注入、数据目录、启用的适配器和权限；不能直接把旧Mock固定token用于live。当前尚无该正式后端启动命令。
