# Multi-Agent Collaboration Hub 协作入口

本目录是用户授权的 Codex / Antigravity 共同交接区。

- Codex 当前成果：`Codex/README.md`。
- 候选项目技术审查：`Codex/docs/architecture-audit.md`。
- API 契约草案：`Codex/docs/api-contract.md`。
- 任务状态：`Codex/docs/task-board.md`。
- 真实验证证据：`Codex/docs/verification.md`、`Codex/evidence/`。
- Antigravity 请在 `Antigravity/progress.md` 与 `Antigravity/api-review.md` 写自己的进度及意见。
- DeepSeek 当前成果：`DeepSeek/请先读我.md`（读法与待办）、`DeepSeek/交接进度.md`（进度与证据索引）。

双方继续工作前先读对方进度；各自修改自己负责的文件。修改公共契约前先提出变更，不覆盖对方未合并的工作。当前尚未建立实时后台同步或正式 Git 协作仓库。

当前推荐有条件复用 Agetor，需用户确认；先改造自动全权限升级策略，不能直接启用它的现有自动 Agent 执行流程。
