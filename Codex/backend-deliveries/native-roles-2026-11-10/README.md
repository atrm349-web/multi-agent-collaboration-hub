# Muse / WorkBuddy 自主分工开放

2026-11-10 按用户明确要求，开放 Muse 和 WorkBuddy 的规划、开发、只读测试及独立审查角色。任务开始前可在新建任务弹窗分别选择主代理、工作模型和独立审查模型。需实际调用规划时选择完整 DAG 拆解模式，快速模式直接提交综合实现节点。

删除原生 runtime 的 read-only 拒绝和 planner 的缺只读策略拒绝。只读角色仍发送不修改源码的指令，平台工作目录边界检查及结构化结果校验继续生效。原生桥接尚未验证具有 OS 级只读隔离，实际模型调用、外部执行停止与恢复待用户实测。

受控适配器测试 8 pass / 0 fail，33 条断言，覆盖两种原生模型通过默认客户端入口规划和执行只读审查。测试拦截客户端方法，未触发桌面 Agent。Hub TypeScript 和前端 JavaScript 语法检查通过。源码锁记录本次开放策略与实际前端哈希。

本次覆盖上一轮交付中关于原生模型禁用的说明。实际启用见 deployment.json，修改文件及替换前内容分别保存在 source 和 source-before，文件哈希见 manifest.json 与 SHA256.json。
